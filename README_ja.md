# Short-stories-by-LLM

**技術的なアイデアをLLMで短編小説にしてみる。**

「Short-stories-by-LLM」は、大規模言語モデル（LLM）を活用して、技術情報や研究成果、あるいは人間が抱くアイデアを短編小説へと変換する試みを探求する実験的プロジェクトです。

本プロジェクトは、物語という形を通じて複雑なアイデアを探求しやすくすること、そして新たな視点や問い、創造的な作品を生み出す機会を創出することを目指しています。

## プロジェクト目論見

専門的な技術知識は、往々にして難解な文書の形で提示されることが多く、予備知識がない人にとってはアクセスしにくいものです。

物語は、こうしたアイデアに触れるための別のアプローチを提供します。科学的な発見や工学的な課題、あるいは対立する見解を、読者が具体的に想像し、議論できるような状況の中に落とし込むことができる点で有利です。

本プロジェクトでは、AIを活用したスト​​ーリーテリングが、いかにして技術知識と人間の好奇心や創造性を結びつけられるかを探求します。

## プロジェクトの内容

- 技術的なトピックや研究資料から短編小説を生成する。
- 特許公報やその他の技術文書をインスピレーションの源として活用する。
- 特定の技術テーマを軸に、多様な登場人物や視点、架空のシチュエーションを探求する。
- AIが生成した物語を、人間による判断と編集を経て検討・洗練させる。

## プロジェクトの進め方

基本的なワークフローは以下の通りです。

1. 技術的なトピック、研究資料、あるいは創造的なアイデアを選定する。
2. 物語の着想となり得る概念や問いを特定する。
3. LLMを使用して短編小説を生成する。
4. 生成された物語の整合性、独創性、そして元資料への忠実度を確認する。
5. 物語を洗練させ、今後の実験に役立つ知見を記録する。

このワークフローや実装方法は、プロジェクトの進展に合わせて変容する可能性があります。

## 実験の方向性

以下のような実験が考えられます。

- 特許公報や先端技術から着想を得たフィクション。
- 科学的発見が日常生活にどのような影響を与えるかを探求する物語。
- 研究者や発明家、そしてその発明を利用する人々を軸にした、キャラクター主導の物語。
- 技術的な課題や、それに対する解決策をめぐる対立的なアプローチを、創造的に解釈した物語。

## プロジェクトのステータス

本プロジェクトは実験的なものです。

リポジトリには、物語のサンプル、プロンプト、ノートなどが、準備が整い次第順次追加される予定です。

## コントリビューションについて

アイデアやフィードバック、プロジェクトへの貢献を歓迎します。技術的なトピックの提案、資料の提示、生成されたストーリーのレビュー、あるいは生成ワークフローの改善案の提案といった形で、プロジェクトにご協力いただけます。
