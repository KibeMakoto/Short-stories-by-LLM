# 制作趣旨

人間が新しいものを発明し、工夫し、昨日より良いものを作り出すことは、喜ばしい営みである。そして、その喜びを互いに支え、次の人に引き継ぐことによって、文明は進歩してきた。

本作品では、半導体の歴史に登場する人々を発明者だけに限定しない。異なる能力を持つ人々が、それぞれの仕事を尊重して協働したことも描く。

これは発明能の価値を薄めることではなく、その価値が社会に実を結ぶ条件を描くものである。

# 制作について

本作品は、ChatGPT（OpenAI）との対話を通じて構想・執筆した技術史フィクションです。歴史上の人物、企業、技術、出来事を題材としています。物語上の会話や描写には創作が含まれます。
